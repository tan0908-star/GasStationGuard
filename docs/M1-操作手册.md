# M1 操作手册 —— 让摄像头画面稳定显示在手机上

> 适用设备：荣耀 200（中国内地版）
> 系统：**MagicOS 10.0.0.175（C00E170R104P1）/ Android 16（API 36）**
> 硬件：骁龙 7 Gen 3 + Adreno 720 / 12GB RAM / 100GB+ 可用空间
> 挂载：横置固定支架（全程锁定横屏）
> 本手册假设你：不会命令行、没用过 Android Studio。每一步都写到"点哪个按钮"。

---

## 〇、先搞清楚：M1 做什么、不做什么

**做：**
- 手机屏幕上**全屏显示摄像头实时画面**
- 画面左上角显示一行小字：状态 / 分辨率 / 帧率 / 已运行时长

**不做：**
- ❌ 不识别车辆 —— 那是 M2
- ❌ 不报警 —— 那是 M3
- ❌ 不后台运行 —— 那是 M4

> ### ⚠️ 安全提示（必读）
> 在 **M3 完成之前**，这个应用**不能用于实际夜班值守**。
> 它现在只是一个"能看画面的相机"，**它不会叫醒任何人**。
> 请务必不要让你母亲在这之前依赖它。

## 一、准备 1：安装 Android Studio

### 1.1 下载

1. 打开浏览器，访问这个网址（中国大陆可直接访问，速度比官网快）：
   ```
   https://developer.android.google.cn/studio
   ```
2. 页面往下滚，找到 **"下载 Android Studio"** 按钮，点击。
3. 弹出条款页面，**勾选"我已阅读并同意"**，然后点下载。
4. 下载的是一个 `.exe` 文件，大约 **1.2 GB**，放在桌面就行。

> 如果上面这个网址打不开，备用官网：`https://developer.android.com/studio`

### 1.2 安装

1. **双击**刚才下载的 `.exe`。
2. 一路点 **"Next"**，中间会遇到一个"选择组件"的页面：
   - ✅ 保留 **Android Studio**
   - ✅ 保留 **Android SDK**
   - ❌ **取消勾选 "Android Virtual Device"**（这是模拟器，我们用真机，装了白白占 5GB）
3. 安装路径：**保持默认**（默认是 `C:\Program Files\Android\Android Studio`）。
   ⚠️ 绝对不要改成带中文的路径。
4. 点 **"Install"**，等 5～15 分钟，完成后点 **"Finish"**。

### 1.3 首次启动（这一步很慢，是正常的）

1. 启动后弹出 **"Import Android Studio Settings"** → 选 **"Do not import settings"**（不导入设置）→ OK。
2. 选安装类型 → 选 **"Standard"（标准）** → Next。
3. 选主题颜色 → 随便选（推荐 Dark 深色）。
4. 确认 SDK 组件列表 → 点 **Next**，然后点 **Accept** 接受许可。
5. **接下来它会自动下载 SDK，几个 GB，视网速 10～60 分钟。**
   窗口上会显示下载进度条，**请不要关闭它**，让它慢慢下完。
6. 全部完成后点 **Finish**，进入 Android Studio 主界面。

## 三、准备 3：在荣耀 200 上打开开发者模式和 USB 调试

### 3.1 打开开发者模式

1. 手机打开 **设置**
2. 拉到最下面，点 **关于手机**
3. 找到 **版本号** 这一行
4. **连续快速点击"版本号" 7 次**（点的时候屏幕下方会倒计时提示"再点 X 次"）
5. 出现提示 **"您已处于开发者模式"** 就成功了

### 3.2 打开 USB 调试

1. 返回 **设置** 首页
2. 点 **系统和更新**
3. 点 **开发人员选项**（如果找不到，直接在设置顶部搜索框输入"开发人员"）
4. 把顶部的 **开发人员选项** 总开关拨到 **打开**
5. 往下找到 **USB 调试**，拨到 **打开**（会弹确认框，点确定）
6. **留意**：如果下面还有一个 **"仅充电模式下允许 ADB 调试"**，把它保持 **关闭**。

> **这是荣耀/华为手机最常见的坑**：如果第 4 步连不上电脑，
> 回到这里，把"仅充电模式下允许 ADB 调试"这个开关**切换一次**
> （关→开，或者开→关），再重新插一次数据线。

> **"USB 调试（安全设置）"** 这个开关我们**不需要**打开（它要登录荣耀账号）。
> 那是用来模拟点击的，我们只是安装 App，用不到。

### 3.3 【顺手做的事】查一下你的 Android 版本

我申请 targetSdk 前需要知道你的确切 Android 版本，**请顺便告诉我**：

1. **设置 → 关于手机**
2. 找到 **版本号**（长这样：`8.0.0.1xx(C00E1R1P1)`）——**把这串完整抄给我**
3. 再找 **Android 版本**（显示 `14` 或 `15`）——**告诉我**
4. 如果 `关于手机` 页面上没直接看到 Android 版本：
   - 用**设置顶部的搜索框**，输入 `Android 版本`
   - 或者打开**电话拨号盘**，输入 `*#*#0000#*#*`，会自动弹出完整版本信息

> 我拿到后会把 `build.gradle.kts` 里的 `compileSdk` / `targetSdk` 锁定成对应值。

## 四、准备 4：用数据线连接电脑

1. 用**原装数据线**（或质量好的数据线）把手机连到电脑 USB 口。
   ⚠️ 很多"只能充电"的劣质线传不了数据，连不上就换一根。
2. 手机屏幕会弹出 **"允许 USB 调试吗？"**：
   - ✅ **勾选"始终允许使用这台计算机进行调试"**
   - 点 **允许**
3. 手机下拉通知栏，把 USB 连接方式从 **"仅充电"** 改成 **"传输文件"（MTP）**。

**验证连接是否成功：**
在 Android Studio 顶部的工具栏，找到中间那个**设备下拉框**（一个手机小图标旁边）。
点开它，如果里面出现了 **你的手机型号**（例如 `HONOR 200`），说明连接成功。

> 如果设备下拉框显示 **"<no device>"** 或一直是空：
> 1. 拔掉数据线，重新插一次，重复上面第 2、3 步
> 2. 换一根数据线
> 3. 换电脑上另一个 USB 口（优先用机箱后面的 USB 口）
> 4. 到"开发人员选项"里把"仅充电模式下允许 ADB 调试"切换一次
> 5. Windows 11 通常会自动装驱动；如果设备管理器里显示黄色感叹号，
>    去荣耀官网下载安装"荣耀手机助手"，它会顺带装好驱动

**✅ 到这一步为止，请停下来告诉我："Android Studio 装好了，手机也连上了"。**
我确认后你再往下做。

## 九、常见错误排查

### 错误 1：Gradle 同步卡住 / 报网络错误 / 下载极慢

> 这是国内用户最常遇到的问题，因为 Gradle 默认从国外服务器下载依赖。

**解决办法：给项目换成国内镜像（阿里云）。**

1. 打开 `settings.gradle.kts`（在 `Gradle Scripts` 分组里）。
2. 找到 `dependencyResolutionManagement { repositories { ... } }` 这一段。
3. 在 `repositories {` 的**最前面**插入下面这段（注意：`google()` 和 `mavenCentral()` 保留，不要删）：

```kotlin
        maven { url = uri("https://maven.aliyun.com/repository/google") }
        maven { url = uri("https://maven.aliyun.com/repository/public") }
        maven { url = uri("https://maven.aliyun.com/repository/gradle-plugin") }
```

4. 保存，点 **Sync Now** 重新同步。

> **注意**：如果用的是新版 Android Studio，`settings.gradle.kts` 里的 `repositories` 可能被
> 包在 `dependencyResolutionManagement` 里，也可能写成 `repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)`，
> 不用管，只是把上面三行 maven 插到 `repositories {` 下面第一行就行。
> **实在搞不定就截图发我，我帮你改。**

---

### 错误 2：`Unresolved reference: databinding` / 找不到 `ActivityMainBinding`

**原因**：`viewBinding` 没开，或者没同步。

**解决**：
1. 打开 `app/build.gradle.kts`，确认 `android { }` 里有这段：
   ```kotlin
   buildFeatures {
       viewBinding = true
   }
   ```
2. **文件（File）→ 将项目与 Gradle 文件同步（Sync Project with Gradle Files）**
3. 如果还报错：**构建（Build）→ 清理项目（Clean Project）**，然后再 **构建（Build）→ 重建项目（Rebuild Project）**

---

### 错误 3：`Unresolved reference: Profile` / `camera-lifecycle 找不到` / CameraX 相关一片红

**原因**：CameraX 依赖没下载成功，或者版本号和你的项目不匹配。

**解决**：
1. 确认 `app/build.gradle.kts` 的 `dependencies` 里有 4 行 `androidx.camera:...`
2. 先做错误 1 的阿里云镜像配置
3. **文件 → 将项目与 Gradle 文件同步**
4. 如果还不行，把 `val cameraxVersion = "1.4.1"` 改成 `"1.4.0"` 再同步试试

### 错误 4：App 装上去了，但屏幕一片黑，什么都没有

**排查顺序：**
1. 屏幕上有没有**红色文字**？有就照着红字做（比如"未获得相机权限"，去设置里开权限）。
2. 左上角诊断条显示什么？
   - `未启动` → 相机根本没起来，把这句话发我
   - `已关闭` + 一直重试 → 被其它应用占用了摄像头。检查有没有别的 App（比如微信视频、相机）在后台用着摄像头，全部划掉重开
3. 有没有装手机壳挡住了摄像头？拆掉壳试试。
4. 打开手机自带的相机 App，确认摄像头本身是好的。

### 错误 5：报错 `Manifest merger failed`

**原因**：`AndroidManifest.xml` 有语法错误，或者和我给的文件没对齐。

**解决**：
用我给的 `AndroidManifest.xml` **整份覆盖**（不要只改一部分），保存后重新同步。

### 错误 6：点运行后，设备下拉框里没有你的手机

**解决**（按顺序试）：
1. 手机屏幕解锁，看有没有"允许 USB 调试"的弹窗，勾"始终允许"再点允许
2. 下拉通知栏，USB 连接方式改成 **"传输文件 / MTP"**
3. 换一根数据线（**这是最常见的原因**）
4. 换电脑上的 USB 口
5. 开发人员选项里，"仅充电模式下允许 ADB 调试"切换一次
6. 重启 Android Studio 和手机

### 错误 7：编译报 `Unsupported class file major version` / JDK 相关错误

**解决**：
1. **文件（File）→ 设置（Settings）→ 构建、执行、部署（Build, Execution, Deployment）→ 构建工具（Build Tools）→ Gradle**
2. 找到 **Gradle JDK** 下拉框，选 **`jbr-17`** 或 **`Embedded JDK`**（Android Studio 自带的）
3. 点 OK，重新同步

### 错误 8：安装时报 `INSTALL_FAILED_USER_RESTRICTED`

**原因**：荣耀手机对"通过 USB 安装应用"有额外限制。

**解决**：
1. 开发人员选项里，找到 **"USB 安装"** 或 **"通过 USB 安装应用"**，**打开**
2. 如果它要求登录荣耀账号，登录一下即可
3. 重试

## 十一、已知问题与后续预告

### M1 阶段已知、且**不打算现在修**的问题

1. **切后台/熄屏就停** —— 这是正常的，M4 会用前台服务解决。
2. **手机重启后不会自动启动** —— M4 解决。
3. **画面卡住不会自动恢复** —— M1 已经做了 5 秒重试，但只有 App 在前台时有效；真正的看门狗在 M4。
4. **不报警** —— M3 解决。

### ⚠️ 提前预警：荣耀 MagicOS 是 M4 最大的敌人

荣耀/华为的 MagicOS 有一个非常激进的**后台清理策略**，会在息屏后杀掉后台应用。
这直接威胁项目验收标准里的"**8 小时不被系统杀掉**"。

M4 阶段我们需要做的**不止是写前台服务**，还要带你完成：
- 关闭"应用启动管理"的自动管理，改为手动管理并全部允许
- 在"电池优化"里把本应用设为**不受限制**
- 在"最近任务"里给应用**加锁**
- 在"应用自启动"里允许自启动和关联启动

**这些开关一个都不能少，少一个就可能半夜被系统杀掉导致漏报。**
到 M4 我会给你带截图级别的步骤。
